# Foaie2Hudl

Un instrument automatizat creat pentru antrenorii și analiștii de performanță din fotbalul juvenil din România, cu scopul de a simplifica munca administrativă de după meci.

## Descriere
Conversia foilor oficiale de arbitraj (în format PDF) în documente structurate de analiză este un proces manual și de durată. **Foaie2Wyscout** extrage automat datele din raportul arbitrului — inclusiv loturile de jucători, numerele de echipament, numele competiției și metadatele meciului — și le formatează într-un fișier `.doc` pregătit pentru importul direct pe platforma Wyscout.

### Funcționalități principale
* **Extragere automată:** Procesează rapoartele PDF ale arbitrilor pentru a colecta titularii, rezervele, numerele de pe tricou și datele despre meci.
* **Formatat pentru Wyscout:** Generează fișiere `.doc` structurate strict conform cerințelor de încărcare ale platformei.
* **Adaptat pentru România:** Optimizat pentru rapoartele de meci utilizate în fotbalul românesc (formatele FRF și AJF).
* **Economie de timp:** Elimină introducerea manuală a datelor și erorile de redactare după fiecare etapă.
